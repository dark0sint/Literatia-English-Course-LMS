# Literatia English Course LMS

A simple offline LMS platform for English courses.

## Setup
1. Install Node.js.
2. Clone or create project folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000 in your browser.

## Features
- Home page with hero section.
- Course listings.
- Lesson pages.
- Quizzes.
- User dashboard.

## Notes
- This is a basic implementation. For production, add authentication, database, and more features.
- Assets (logo.png, background.jpg) are placeholders; replace with your own.
